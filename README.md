# 삭발봇 v2

랏코 서버 내전 + 사이트(Supabase) 연동 봇.

## 처음 한 번만 할 일
1. **DB 마이그레이션 적용**: Supabase 대시보드 → SQL Editor에 `migrations/001_bot_v2.sql` 전체를 붙여 넣고 실행
   - 컬럼·테이블·함수 추가, 기존 옵치 점수 → 포지션 선호(주/부/안 함) 자동 변환
   - ⚠️ **롤 티어·점수·포지션·승패를 초기화**해요 (경기 이력은 보존). 여러 번 실행해도 안전해요
2. **`.env` 설정**: `.env.example` 참고. 봇은 `SUPABASE_SERVICE_KEY`(service_role 키)를 써요
3. `pip install -r requirements.txt` 후 `python main.py`

## 내전 흐름
1. `/모집` → 참가 → **팀 짜기**
2. 팀 화면: 포지션별 맞대결(🔵 vs 🔴)과 예상 승률 표시
   - **🔁 자리 바꾸기**: 두 사람을 고르면 팀+포지션을 통째로 맞바꿈 (같은 팀 둘이면 포지션만)
   - **🔀 다시 섞기**: 비슷하게 균형 잡힌 다른 조합
   - **🔊 통화방 이동**
3. 승리 팀 버튼 → 점수 반영 → **같은 팀으로 한 판 더 / 다시 밸런싱해서 한 판 더 / 명단 수정(대기실로)**

## 오버워치 밸런싱 (`core/balancer.py` 맨 위 튜닝값)
- **포지션 선호**: 주 / 부 / 안 함. '안 함'은 인원 구성상 어쩔 수 없을 때만 배정 (⚠️ 표시)
- **점수 변동**: 경기 전 예상 승률 E 대비 결과로 `Δ = K × (결과 − E)`
  - K: 그 포지션 5판 미만 80 / 15판 미만 60 / 이후 40 → 50:50 경기 기준 ±40 / ±30 / ±20
  - 예상을 깨고 이기면 많이, 이길 만한 경기를 이기면 조금
  - '안 함' 포지션으로 뛴 판은 점수 변동 없음
- **팀 평가 함수** (작을수록 좋음): '안 함' 배정 ×1000 + 예상 승률 50%에서 벗어난 %p ×10 + 포지션 맞대결 점수차(100점당, 탱커 ×1.3) ×1.5 + 부 포지션 배정 ×12 + 최근 8판에서 같은 팀이었던 쌍 ×1.5
- **티어 표시**: 옛 경쟁전 점수 기준 (브론즈 1000 · 실버 1500 · 골드 2000 · 플래티넘 2500 · 다이아 3000 · 마스터 3500 · 그마 4000 · 챔피언 4500, 디비전당 100점)
- `/등록`의 티어는 첫 점수로만 쓰여요. 한 포지션에서 5판 이상 뛰면 본인은 다시 고를 수 없어요 (소유자는 가능)

## 자동으로 돌아가는 것
- **입장** → DB 프로필 생성 (종족 역할 → 팀). **퇴장** → '퇴장' 표시 → `LEAVE_PURGE_DAYS`(기본 7일) 뒤 매일 04시에 삭제, 그 전에 돌아오면 복구
- 채팅 수·포인트는 15초마다 모아서 한 번에 반영
- 연동된 배틀태그 랭크 매일 05시 갱신, 생일 축하 00시, 오래된 대기실 정리

## 파일 구조
```
main.py            봇 시작, 코그 로드, 공통 에러 처리
config.py          채널/역할/태그 ID, 설정값
core/db.py         Supabase 비동기 클라이언트
core/ranks.py      티어·점수 변환, 프로필 파싱
core/balancer.py   팀 밸런싱 + 오버워치 레이팅 (튜닝값은 파일 맨 위)
core/recording.py  경기 1판 기록 (대기실 · /옵치경기기록 공용)
core/overfast.py   오버워치 인게임 랭크 조회 (재미용)
cogs/members.py    입·퇴장 동기화, 채팅 집계, 생일
cogs/profile.py    등록/수정/조회/옵치연동, 소유자 명령어
cogs/lobby.py      /모집 → 대기실 → 팀 → 결과 → 한 판 더
cogs/history.py    /전적, /되돌리기, /밸런스통계
cogs/schedule.py   포럼 일정 → 사이트 캘린더
cogs/map_picker.py, hero_picker.py   랜덤맵/랜덤캐릭터
migrations/        DB 변경 SQL
```
